# TravelMate React Travel Booking UI

## Pages
1. Home
2. Destinations
3. Destination Details
4. Packages
5. Booking
6. About

## Features
- React Router
- Responsive mobile navigation
- Dynamic destination data
- Search and category filtering
- Package filtering
- Destination detail pages
- Booking form validation and success state
- Reusable React components
- CSS Grid and Flexbox
- Responsive design
- Unsplash travel images

## Run
npm install
npm run dev

## Build
npm run build

This is a frontend UI project; no backend/payment processing is connected.
